# Gold Coast Motors — homepage prototype

Static prototype of the Gold Coast Motors homepage (Naperville, IL), direction E.

- `index.html` — the page (HTML, CSS and JS inline; GSAP 3.12.5 + ScrollTrigger and MapLibre load from CDNs).
- `assets/` — optimised images used by the page.

Open `index.html` through any static server, e.g. `python -m http.server`.

Premier listing details and the reviews are sample content for the layout; they are marked as such on the page.
